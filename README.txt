# Liam Jilla Counselling website

This is a responsive, single-page website draft for Liam Jilla Counselling.

## Preview
Open `index.html` in a web browser.

## Before publishing
1. Open `index.html` in a text editor.
2. Find `REPLACE-WITH-YOUR-EMAIL@example.com` near the bottom of the file.
3. Replace it with your professional enquiry email address.
4. Review all wording, professional details, service scope and fees.
5. Add your final privacy policy, cancellation/payment terms, consent process and any relevant professional registration details.
6. Consider a secure hosted form provider if you want enquiries submitted without opening the visitor's email app.

## Important
- The enquiry form currently uses a `mailto:` link. It does not store or transmit form submissions to a server.
- The website is a draft and should be reviewed for professional, legal, privacy, child-safety and advertising compliance before going live.
- No appointment booking system or payment processing is connected.
